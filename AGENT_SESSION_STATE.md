# Agent Session State: ODB Processing App

## Текущая задача
Разработка десктопного приложения на PyQt6 для автоматизированной экстракции, обработки и визуализации данных из файлов .odb Abaqus.

## Что уже сделано
- **Архитектура**: Реализован паттерн MVC (Model-View-Controller).
- **GUI**: 
    - Главное окно с разбивкой 30/70.
    - Левая панель управления с деревом объектов, прогресс-баром и аккордеонами настроек.
    - Интерактивный график на базе Matplotlib с поддержкой X-Y осей.
    - Диалог калькулятора полей для мат. операций над временными рядами.
- **Интеграция с Abaqus**:
    - Реализован `AbaqusBridge` использующий `abaqus python` для обхода лицензионных ограничений CAE.
    - Скрипт `odb_extractor.py` для полной выгрузки данных в структурированные CSV.
- **Обработка данных**:
    - Автоматическая агрегация (Mean, Max, Min).
    - Обработка инвариантов (Mises для Stress, Max Principal для Strain).
    - Загрузка уже распаршенных данных из папок.

## Опробованные шаги и проблемы
- **Проблема 1**: Ошибка лицензии при использовании `abaqus cae noGUI`.
    - **Решение**: Переход на `abaqus python`.
- **Проблема 2**: Ошибки типов (`unicode` в Python 2.7).
    - **Решение**: Добавлена функция `byteify` для конвертации JSON-аргументов.
- **Проблема 3**: Ошибки `numpy.ndarray` при извлечении векторных полей.
    - **Решение**: Принудительное приведение к `float` и обработка магнитуды векторов.
- **Проблема 4**: Ошибка `global name 'info' is not defined` в `odb_extractor.py`.
    - **Решение**: Логика фильтрации полей перенесена внутрь цикла по инстансам.
- **Проблема 5**: Необходимость ручной настройки осей графика.
    - **Решение**: Добавлены виджеты управления лимитами (Xmin, Xmax, Ymin, Ymax) в ControlPanel с поддержкой переключения между авто-масштабированием и ручным вводом.
- **Проблема 6**: Вылет программы (crash) при отсутствии файлов данных (FileNotFoundError).
    - **Решение**: В Controller добавлена обработка исключений (try-except) при загрузке данных с выводом предупреждающего сообщения через QMessageBox.
- **Проблема 7**: Сохранение и загрузка данных.
    - **Решение**: Добавлены функции ручного сохранения данных с графиков в CSV, XLSX. Добавлен функционал сохранения и загрузки сессии  (в том числе данных и графиков) в формат lnbodb.
- **Проблема 8**: Документация
    - **Решение**: Добавлен README.md с описанием приложения, функциями, настройками и примерами использования.

## Инструкции для следующего агента
- Скрипт экстракции должен оставаться совместимым с Python 2.7 (Abaqus).
- При добавлении новых полей в CSV обновляйте логику сканирования в `Model.load_from_csv_root`.
- Не забывайте про очистку временных файлов `abaqus.rpy*`.

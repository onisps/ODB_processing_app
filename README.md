# ODB Processing App — руководство пользователя

Это десктопное приложение для автоматизированной экстракции, обработки и визуализации данных из файлов **Abaqus `.odb`**.

Приложение работает в два этапа:
1) Быстро «сканирует» ODB и показывает, **какие** FieldOutput/HistoryOutput доступны для экспорта (компоненты и инварианты).
2) По выбранным фильтрам выполняет **экспорт в CSV** и позволяет строить графики, сравнивать кривые и выполнять вычисления над рядами.

---

## 1. Что требуется от пользователя

### 1.1. Обязательные требования

- **Windows** (приложение упаковано и тестировалось под Windows).
- **Установленный Abaqus** на этом компьютере.
- **Лицензия Abaqus** (нужна для открытия `.odb` и извлечения данных).
- Доступ к `.odb` файлам (локально или по сети).

Важно: приложение не «встраивает» Abaqus внутрь себя. Оно запускает внешний процесс Abaqus (через `abaqus python`) для чтения ODB.

### 1.2. Настройка команды `abaqus` (если нужно)

По умолчанию приложение пытается вызвать команду `abaqus` из PATH.

Если на компьютере команда `abaqus` не находится, нужно указать переменную окружения:

- `ABAQUS_CMD` — путь до `abaqus.bat` (или команды Abaqus).

Пример:
- `ABAQUS_CMD=C:\SIMULIA\Commands\abaqus.bat`

## 2. Установка и запуск

### 2.1. Что нужно передать коллеге

Для запуска на другом ПК передавайте **всю папку**:

- `dist\ODBProcessingApp\`

Запускать нужно:
- `dist\ODBProcessingApp\ODBProcessingApp.exe`

Не запускайте «одиночный exe» из корня `dist` (если он присутствует). Рабочий вариант для распространения — папка `dist\ODBProcessingApp\`.

### 2.2. Первый запуск

1) Запустите `ODBProcessingApp.exe`.
2) Нажмите **Load ODB File** и выберите `.odb`.
3) Дождитесь шага «сканирования» (быстрое построение списка доступных данных).
4) В окне выбора отметьте галочками, что именно нужно экспортировать:
   - нужные поля (FieldOutput), их компоненты и/или инварианты
   - нужные HistoryOutput
   - нужные агрегации (Mean/Max/Min/Boxplot stats)
5) Нажмите **OK** — начнётся экстракция.
6) После окончания данные появятся в дереве, можно строить графики.

## 3. Где сохраняются результаты

### 3.1. Экспортированные данные (CSV)

Папка экспорта зависит от способа запуска:

- При запуске **из собранного `.exe`**:
  - `extracted_data` создаётся **рядом с `.exe`**
  - путь: `<папка_где_лежит_ODBProcessingApp.exe>\extracted_data\...`

- При запуске **из исходников (IDE/venv)**:
  - `extracted_data` создаётся **рядом с выбранным `.odb`**
  - путь: `<папка_с_файлом.odb>\extracted_data\...`

Внутри создаётся подпапка вида:

- `<имя_odb>_<YYYY-MM-DD_HH-MM-SS>`

### 3.2. Временные файлы работы Abaqus (лог/конфиг/ошибки)

Для каждого запуска Abaqus создаётся рабочая папка:

- `<папка_приложения>\abaqus_work\run_<uuid>\`

Там находятся:
- `abaqus_input.json` — параметры запуска (внутренний файл)
- `abaqus_error.log` — traceback при ошибке (если произошла)
- `abaqus_stderr.log` — stderr Abaqus (если был)

Эти файлы нужны для диагностики проблем (лицензия, падение Abaqus, ошибки скрипта).

## 4. Что умеет приложение (функционал)

### 4.1. Экстракция данных из ODB

Поддерживаются:

- **Field Outputs** (`frame.fieldOutputs`):
  - экспорт по компонентам тензора/вектора через `componentLabels` (например `S11`, `LE23`, `U1`)
  - экспорт инвариантов через `validInvariants` и `getScalarField(invariant=...)` (например `MISES`, `MAX_PRINCIPAL`, `TRESCA`)
- **History Outputs** (`step.historyRegions[].historyOutputs`)

Экстракция выполняется по выбранным фильтрам пользователя.

### 4.2. Агрегации по полю

Для каждого выбранного FieldOutput/варианта можно сохранять:
- **Mean**
- **Max**
- **Min**
- **Boxplot stats** (Min, Q1, Median, Q3, Max)

Агрегации рассчитываются по множеству значений в срезе (по выбранной области/телу).

### 4.3. Визуализация (графики)

- Построение нескольких кривых на одном графике.
- Управление X‑осью: по времени или по другой выбранной серии (X‑Y режим).
- Настройки графика: сетка, логарифмические оси, толщина линии, авто‑масштаб или ручные лимиты.
- Для Boxplot stats:
  - линия Median
  - заливка Q1–Q3 и Min–Max

### 4.4. Управление видимостью кривых

В дереве данных есть столбец **Series**:
- Для каждой построенной серии появляется чекбокс.
- Снятие галочки скрывает кривую (и заливки для boxplot), установка — показывает.

### 4.5. Калькулятор полей

Можно создавать «виртуальные» ряды данных:

1) **Binary** режим: операции между двумя сериями: `+`, `-`, `*`, `/`.
2) **Expression** режим: выражения с константами и функциями:
   - `sin(var)`, `cos(var)`, `tan(var)`, `sqrt(var)`, `log(var)`, `exp(var)`, `abs(var)`
   - поддерживаются `+ - * / **` и скобки

Переменные выбираются из списка уже построенных/активных серий и вставляются в выражение кнопкой.

## 5. Как пользоваться (пошагово)

### 5.1. Экспорт данных из ODB

1) Нажмите **Load ODB File**.
2) Выберите `.odb`.
3) В окне «Export Selection» отметьте:
   - Instances → Body → Field → Variant (компонента или инвариант)
   - History Outputs → нужные переменные
   - нужные агрегации
4) Нажмите **OK**.
5) Дождитесь окончания прогресса.

Результат: приложение сохранит CSV и отобразит структуру в дереве.

### 5.2. Построение графика

1) В дереве раскройте:
   - `Instances → <instance> → <body> → <field> → <variant> → <aggregation>`
2) Дважды кликните по строке с нужной агрегацией.
3) Серия построится на графике и появится чекбокс Series.

### 5.3. Скрыть/показать кривую

- В дереве в столбце **Series** снимите/поставьте галочку у соответствующей строки.

### 5.4. Загрузка уже распарсенных данных (без Abaqus)

Если у вас уже есть папка с извлечёнными CSV:
1) Нажмите **Load Parsed CSVs**.
2) Выберите корневую папку экспорта (ту, где лежат `Instances/History`).

Результат: дерево и графики будут доступны без запуска Abaqus.

### 5.5. Очистка графика

- Нажмите **Clear Plot**.
Результат: график очистится и чекбоксы Series сбросятся.

## 6. Типовые ошибки и диагностика

### 6.1. «Abaqus process exited with code 1»

Это означает, что Abaqus или скрипт экстракции завершился с ошибкой.

Действия:
1) Скопируйте путь `Work dir` из сообщения об ошибке.
2) Откройте эту папку и посмотрите:
   - `abaqus_error.log` (traceback)
   - `abaqus_stderr.log` (сообщения Abaqus/лицензии)

Частые причины:
- Abaqus не установлен или не находится команда `abaqus` (PATH/ABAQUS_CMD).
- Проблема с лицензией.
- `.odb` недоступен/заблокирован/повреждён.
- Права на запись в папку экспорта.

### 6.2. Не появляются CSV после экспорта

Проверьте:
- Папку `extracted_data` (рядом с exe или рядом с `.odb`, в зависимости от запуска).
- `Work dir` и логи, если экспорт прерывается.
